Amalgamation

An Library System Currently Supporting Fabric & Neoforge

Overview

Amalgamation is a Library system that assists in various things. This is to prevent any possible overlap and issues with the code. This is all possible on the latest version (Currently 26.2)

Adding to your Mod

  1. Add Modrinth Maven to your repositories
    2. repositories {
    exclusiveContent {
        forRepository {
            maven {
                name = "Modrinth"
                url = "https://api.modrinth.com/maven"
            }
        }
        filter {
            includeGroup "maven.modrinth"
        }
    }
}
  2. Add Amalgamation as a dependency using its latest version under dependencies (please go to Modrinth if your after an older version)
    3. dependencies {
    implementation "maven.modrinth:amalgamation-library:coming_soon"
}
